# 会话搜索界面对齐 SOP

以 DeepSeek 官网为交互参考，针对 Demo 的侧栏会话搜索，逐状态核对入口、信息层级、结果反馈、键盘操作和动效。界面使用 Demo 自有标识、组件和视觉样式。历史检索范围、数据读取和消息定位沿用现有功能验收。[UI 走查](frontend-experience-review.md#fe-07-会话搜索弹窗对照) · [开发计划](PDP.md#历史会话搜索界面对齐) · [历史会话搜索功能 SOP](session-search-sop.md)

## 1. 准备基线与样本

1. 解压 `deepseek-search-reference-20261119.zip`，从包内 `README.md` 找状态编号。采集日期为 2026-11-19，桌面 Chromium 为 1440 × 900，窄屏为 390 × 844，单位为 CSS 像素。使用全屏图比较入口、位置和遮罩，用 `-detail` 近景比较输入行、结果密度和高亮。录屏 `desktop-motion.webm` 与 `frames/` 用于复查状态切换。归档 SHA-256 为 `d5011139cf7ba56e4e8a73b8d503addc51978c4f192ca44ed855258a118d1530`。
2. 在 Demo 以相同视口、主题和 100% 浏览器缩放复拍，记录浏览器版本、设备像素比、动效偏好及构建版本。用本地固定样本「星图记录」「晨星样本」「夜航样本」覆盖标题、提问和回答，再准备同会话多命中、长标题和长列表。测试账号截图须遮挡无关会话和账号信息。[样本与功能用例](session-search-sop.md)

## 2. 实施与复拍

| 顺序 | 官网参考编号 | Demo 实施及通过条件 |
| --- | --- | --- |
| 1 | 01–04、12、20–22、25 | 三种侧栏入口打开同一搜索流程。桌面空查询只显示已聚焦的输入行，清空后恢复单行。窄屏提供独立搜索视图，内容可滚动且关闭操作始终可达。浅色和深色都核对遮罩、输入文字与焦点的可辨识度。 |
| 2 | 05–07、10–11、17、23–24、26，录屏加载关键帧 | 有关键词才显示结果区。分别验证标题、提问与回答命中，正文结果显示标题和高亮摘要，同会话多条命中可分别选择。区分读取中、无匹配、读取失败，保留已有结果和重试路径。用受控慢读样本验证过期查询不会覆盖当前结果。 |
| 3 | 08–09、13–15 | 验证悬停和键盘选中反馈。上下键可移动结果选中，Enter 打开当前结果，Tab 可访问关闭与结果控件，键盘焦点始终可见。Escape 和遮罩取消后恢复入口焦点并保留草稿。选中正文结果后关闭弹窗，窄屏同时关闭抽屉，原消息进入视口且自动跟随不会把它滚走。 |
| 4 | 12、16、录屏及关键帧 | 复拍打开、输入展开、清空收回和关闭四段。桌面开关以约 `100ms`、缩放 `0.96` ↔ `1`、遮罩同步淡入淡出为参考。浏览器按动画属性校验声明值，用帧序列观察是否跳帧或闪回。快速开关和连续改词以最后一次操作为准。减少动态效果时直接显示终态。 |

改动优先集中在搜索弹窗、样式和键盘交互。对照表中的官网尺寸作为对应视口的实测值，拟定 Demo 尺寸时同时验证短视口、触控和可见焦点。加载反馈用本地读取耗时触发。网络面板确认搜索词与正文在浏览器内处理。[搜索组件](../web/src/components/sider/SessionSearch.tsx) · [弹窗样式](../web/src/components/sider/SessionSearch.module.css)

## 3. 补测与记录

逐项记录「参考编号、环境、操作、预期、实际、Demo 截图或录屏、结论」。使用「通过」「有差异」「未验证」标注状态，说明影响和复测方法。慢网或离线失败提示、长列表到底、长标题截断、输入法候选和真机软键盘缺少官网参考。对这些状态先验收 Demo 的滚动、重试、输入法组合期和软键盘布局，再按相同条件补采官网证据。录屏里的骨架来自正常连接，窄屏截图来自桌面 Chromium。官网完整排序及未选分支的检索规则仍待确认。

## 4. 候选与发布验收

1. 桌面浅色跑完整流程，再复测深色、390 × 844 窄屏和减少动态效果。刷新后重新搜索未预先打开的旧会话，验证草稿、消息定位与普通对话。按编号保存复拍记录，列明尚待补采的状态。
2. 在 `web/` 依次执行 `pnpm type`、`pnpm lint` 和 `pnpm build`。通过后记录候选构建、参考包校验值、已验收范围和剩余差异。[前端脚本](../web/package.json)
3. 发布后在目标站复验打开、正文命中、清空、键盘取消和消息定位，并发送一条普通消息。若出现误开会话、草稿丢失、弹窗无法退出或普通对话回归，回到上一已验证版本并重跑对应路径。[发布和回滚 SOP](sop.md)
